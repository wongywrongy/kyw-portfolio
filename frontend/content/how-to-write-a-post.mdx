Posts are MDX (or plain `.md`) files in `frontend/content/posts/`. The file name becomes the URL, so `my-post.mdx` is served at `/blog/my-post`. You can also write and edit them in Pages CMS under **Blog**.

## Frontmatter

Every post starts with a block like this:

```yaml
---
title: My post
date: 2026-10-01
summary: One line that shows up in link previews.
cover: /images/my-cover.jpg
draft: false
---
```

- `title` and `date` are required. The build fails with the file name if either is missing.
- `date` is `YYYY-MM-DD`.
- `summary` shows under the newest post on the homepage and in link previews.
- `cover` is optional. It shows in the blog list and at the top of the post. Without one, the post gets generated square art that stays the same between builds.
- `draft: true` hides the post from the homepage, the sitemap and the build. Drafts only show up under `npm run dev`.

## Images

Put images in `frontend/public/images/` and reference them from the root:

```md
![Alt text](/images/my-photo.jpg)
```

## Code

Fenced blocks are highlighted automatically:

```ts
type Post = { slug: string; title: string; date: string }

export function newest(posts: Post[]) {
  return [...posts].sort((a, b) => b.date.localeCompare(a.date))
}
```

Flip `draft` to `false` when you're ready to publish.
